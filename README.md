# dsh-opengrokbot-site

npm 包 [dsh-opengrokbot](https://www.npmjs.com/package/dsh-opengrokbot) 的公开介绍站。站点是仓库根目录的 `index.html` 和 `styles.css`，没有构建。

## 打开 GitHub Pages

页面从 `main` 分支的根目录发布，不用登录就能打开：

https://xiaoxin1358.github.io/dsh-opengrokbot-site/

如果打不开：仓库 Settings → Pages → Build and deployment → Deploy from a branch，Branch 选 `main`，文件夹选 `/ (root)`，保存后再打开上面的地址。根目录的 `.nojekyll` 让 Pages 按原样提供这些静态文件。
